# @ninoverse/hmi-components

Native custom elements, `hmi-<name>`, for Human-Machine Interface (HMI)
screens: they work in plain HTML, React, Vue, Angular, Svelte and Dioxus alike,
on Material Design 3 color tokens with a warm, asymmetric styling system.

Browse the elements in the sidebar. Every page is generated from the
properties, slots, parts, events and doc comments in the source, so the tables
stay in step with the code.

## The demo pages

Storybook shows one element at a time. The demo pages put them to work in
small apps, each with its own data and layout, such as an operations
dashboard, and the reference page shows every element at once.

## Theming

Three axes switch independently from the toolbar above, and they compose.
(Markdown tables need remark-gfm, which is not wired up — hence the list.)

- **Color** — `html[data-theme]` — `default`, `ocean`, `forest`
- **Structure** — `html[data-structure]` — `default`, `rounded`, `sharp`,
  `pixel`, `journal`
- **Material** — `html[data-material]` — `solid`, `glass`, `liquid`

Light and dark follow the OS setting via `prefers-color-scheme`.

## Installation

```bash
pnpm add @ninoverse/hmi-components
```

Import the elements you use, and load the base stylesheet with one theme per
axis:

```ts
import '@ninoverse/hmi-components/wc/button';
import '@ninoverse/hmi-components/base.css';
import '@ninoverse/hmi-components/themes/constants.css';
import '@ninoverse/hmi-components/themes/color/default.css';
import '@ninoverse/hmi-components/themes/structure/default.css';
```

React gets a wrapper per element, named as the v5 component:
`import { Button } from '@ninoverse/hmi-components/react/button'`, with React
^19 as a peer dependency. Until 6.0 the package root is still the v5 React
library.
